# EchoNote Brand Assets

Production logo assets for EchoNote.

## Recommended usage

| Context | Asset |
|---|---|
| Website navbar | `frontend/public/brand/echonote-logo.svg` |
| Dark UI / hero | `frontend/public/brand/echonote-logo-dark.svg` |
| Mobile navigation | `frontend/public/brand/echonote-mark.svg` |
| Favicon | `frontend/public/brand/favicon.svg` |
| App icon | `frontend/public/brand/echonote-app-icon.svg` |
| Marketing / docs | `docs/brand/echonote-lockup.svg` |

## Brand colors

- Navy: `#0F172A`
- Blue: `#2563EB`
- Cyan: `#06B6D4`
- Teal: `#14B8A6`
- Violet: `#8B5CF6`
- Light: `#F1F5F9`

## Next.js

The App Router references `/brand/favicon.svg` and `/brand/echonote-app-icon.svg` through the root metadata configuration.

## Clear space

Keep at least the height of the mark's middle stroke around the logo. Do not place text, UI controls, borders, or other marks inside this area.

## Don't

- Stretch or skew the logo.
- Add drop shadows or outlines to the logo.
- Recolor the gradient arbitrarily.
- Place the full logo on busy imagery.
- Use the detailed lockup at favicon size.
