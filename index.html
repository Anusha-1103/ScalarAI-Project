Product workflow

From raw conversation to work that moves

EchoNote keeps every generated insight connected to the original transcript and the account that owns it.

01

Enter the workspace

Sign in with Supabase Auth. Personal accounts start private and empty, with an optional sample workspace available from the empty state.

02

Add a conversation

Paste dialogue or upload a TXT, VTT, or JSON transcript with participants and meeting time.

03

Generate intelligence

Groq creates a concise overview, key points, chapters, and explicit actions with matched owners.

04

Review exact moments

Search and filter the transcript, edit wording, save moments, and seek to timestamped context.

05

Ask the meeting memory

Ask Echo retrieves tenant-scoped evidence, synthesizes an answer, and links every source.

06

Close the loop

Assign, edit, complete, and export follow-ups while the dashboard tracks workspace progress.
